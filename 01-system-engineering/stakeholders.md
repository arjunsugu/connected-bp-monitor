# Stakeholder Analysis

## Purpose

Identify stakeholders who have needs, expectations, constraints,
authority, influence, or dependencies related to the Connected
Blood Pressure Monitoring System.

## Stakeholder Categories

### Primary Users
- Patient / User
- Caregiver / Family
- Healthcare Professional

### Product & Business
- Product Manager / Product Owner
- Marketing / Commercial
- Business Leadership
- Clinical / Medical Expert

### Engineering
- Systems Engineer
- Design Engineer
- Hardware Engineer
- Software Engineer
- AI / Data Engineer
- Manufacturing Engineer
- Tooling Engineer

### Quality & Compliance
- Quality Engineer
- Software Quality Engineer
- Test / V&V Engineer
- Regulatory Affairs
- Cybersecurity / Privacy
- Supplier Quality

### Operations
- Supply Chain / Procurement
- Manufacturing
- Service / Support
- Suppliers

## Stakeholder Needs

| Stakeholder | Key Needs / Expectations |
|---|---|
| Patient / User | Easy to use, safe, comfortable, accurate and trustworthy |
| Caregiver | Easy monitoring, understandable trends and reliable data |
| Healthcare Professional | Accurate, reliable and clinically useful information |
| Product Manager | User value, priorities, resources, timeline and business outcome |
| Marketing | Market need, competition, differentiation and ROI |
| Systems Engineer | Stakeholder needs, requirements, architecture and system integration |
| Design Engineer | Specifications, components, materials and manufacturability |
| Hardware Engineer | Sensors, PCB, MCU, memory, power and connectivity |
| Software Engineer | Clear requirements, architecture, implementation and defect resolution |
| Software Quality | Requirements, traceability, risk controls, verification and defects |
| Test / V&V | Test methods, test cases, evidence and objective results |
| Regulatory | Intended use, classification, regulatory pathway and evidence |
| Manufacturing | DFM/DFA, process capability, equipment and assembly |
| Tooling | Tool design, molding and tooling validation |
| Supply Chain | Sourcing, procurement, inventory and supply continuity |
| Supplier Quality | Supplier capability, quality controls and incoming inspection |
| AI / Data | Data quality, analytics, model performance and monitoring |
| Cybersecurity / Privacy | Data protection, security and privacy |
| Clinical / Medical | Clinical relevance and appropriate interpretation |
| Service / Support | Troubleshooting, maintenance, complaints and field failures |

## Key Insight

The Connected BP Monitor is a socio-technical system involving
users, healthcare, engineering, quality, regulatory, manufacturing,
operations, software, data and business stakeholders.

Stakeholder needs will be progressively refined into user needs,
system requirements and verification criteria.
