# Connected Blood Pressure Monitor — Systems Engineering

## Overview
Hands-on Systems Engineering project to design and prototype a connected blood pressure monitoring system, covering requirements, system architecture, risk management, software quality, verification &amp; validation, and AI-enabled product development

This is a hands-on Systems Engineering and product development project to design and prototype a connected blood pressure monitoring system.

The project is being developed as a practical learning and portfolio project to build competency across:

- Systems Engineering
- Requirements Engineering
- System Architecture
- Risk Management
- Software Quality
- Verification & Validation
- Medical Device Product Development
- Embedded Systems
- Data & AI
- Product Management

## Objective

Design an end-to-end connected blood pressure monitoring system that demonstrates how a medical-device concept can evolve from:

User Needs
→ System Requirements
→ System Architecture
→ Component Design
→ Prototype
→ Software
→ Verification & Validation
→ Data
→ AI-enabled Insights
→ Product Strategy

## System Concept

Cuff
→ Pressure Measurement
→ Embedded Controller
→ Connectivity
→ Application
→ Data Storage
→ Analytics / AI

## Systems Engineering Framework

The project applies concepts from the INCOSE Systems Engineering Handbook and is being developed alongside preparation for the INCOSE Associate Systems Engineering Professional (ASEP) certification.

Key areas include:

- Stakeholder needs
- User needs
- System requirements
- Requirements traceability
- System architecture
- Functional decomposition
- Interfaces
- Risk management
- Verification
- Validation
- Configuration management
- Technical decision making

## Medical Device Quality

Relevant concepts and standards will be studied and applied where appropriate, including:

- ISO 14971 — Risk Management
- IEC 62304 — Medical Device Software
- IEC 62366 — Usability Engineering
- ISO 13485 — Quality Management Systems
- Applicable FDA / EU regulatory concepts

This is an educational engineering prototype and is not intended for diagnosis, treatment, or clinical use.

## Engineering Philosophy

> Learn fast. Build fast. Fail fast. Iterate fast. Repeat.

The objective is not simply to complete a prototype, but to document the engineering decisions, failures, trade-offs and lessons throughout the development lifecycle.

## Disclaimer

This project is for educational and engineering learning purposes only. It is not a clinically validated medical device and must not be used for medical diagnosis or treatment.
